# 上位机接入说明

## 1. 交付文件

Release 构建后，上位机至少需要以下文件：

- `Seprays.MarkVision.dll`
- `halcondotnet.dll`
- 当前设备已安装且与 `halcondotnet.dll` 对应的 HALCON 19.11 x64 Runtime

项目目标框架为 `.NET Framework 4.7.2`，平台为 `x64`。

## 2. 新旧流程映射

| 原 Seprays.Vision 流程 | 新流程 | 说明 |
| --- | --- | --- |
| `DealShapeModel` | `OpenSetupDialog` | 模板 ROI 确定后自动提取离散特征点，可擦除不稳定点后建模。 |
| 保存 `Bitmap Mark` | 保存 `MarkLocateJob` | Job 包含 ROI、匹配参数、擦除笔划、特征点和模型字节。 |
| `FindShape` | `RunInspection` | 仍使用 `FindScaledShapeModel`，返回中心、分数、角度、缩放和轮廓。 |
| `FindResult.ModelPoint` | `MarkLocateResult.ModelPoint` | 坐标均为原图像像素坐标。 |
| `FindResult.Score` | `MarkLocateResult.Score` | HALCON 形状匹配分数。 |

原算法的主要顺序保持不变：模板预处理、缩放形状模型、运行图预处理、搜索范围、缩放形状匹配。创建模型前新增外轮廓流程：模板 ROI 内执行亚像素边缘提取，将擦除笔划应用到离散特征点，再通过 `CreateScaledShapeModelXld` 创建模型。

## 3. 对话框方式

```csharp
using Seprays.MarkVision;

private readonly MarkLocatorSdk _markSdk = new MarkLocatorSdk();
private MarkLocateJob _markJob;

private void ConfigureMark(Bitmap cameraImage)
{
    MarkLocateJob edited = _markSdk.OpenSetupDialog(cameraImage, _markJob);
    if (edited != null)
    {
        _markJob = edited;
        // MarkLocateJob 由上位机写入自己的产品配置。
    }
}

private MarkLocateResult FindMark(Bitmap cameraImage, bool saveResultImage)
{
    MarkLocateResult result = _markSdk.RunInspection(
        cameraImage,
        _markJob,
        returnResultImage: saveResultImage);

    if (!result.Success)
    {
        // 上位机记录 result.Message，并按定位失败处理。
    }

    if (result.ResultImage != null)
    {
        try
        {
            result.ResultImage.Save(@"D:\Result\mark-result.png");
        }
        finally
        {
            result.ResultImage.Dispose();
            result.ResultImage = null;
        }
    }
    return result;
}
```

用户取消设置对话框时返回 `null`，原 Job 不会被修改。

`MarkLocatorSdk` 只公开 `OpenSetupDialog` 和 `RunInspection` 两个方法，均没有重载。

## 4. 图像所有权

- SDK 不会释放、修改或长期持有上位机传入的 `Bitmap`；传入图像仍由上位机负责释放。
- `returnResultImage=false` 时不生成效果图，`ResultImage` 为 `null`。
- `returnResultImage=true` 时只把效果图返回给上位机，不会自行保存文件。
- 非空的 `ResultImage` 是独立图像，归上位机所有；保存或显示完毕后必须调用 `Dispose()`。

## 5. 特征点和掩膜语义

- 模板 ROI 创建或拖动完成后，页面自动提取并显示橙色离散特征点。
- 页面支持圆形、矩形、菱形三种模板 ROI，默认圆形。圆形采用圆心向外创建和四个半径控制点等比缩放；矩形使用八个控制点；菱形使用四个顶点。形状保存在 `MarkLocateJob.TemplateRoiShape`。
- 区域掩膜支持同样的三种形状，默认圆形；选择“区域排除/区域恢复”后拖拽即可创建区域，也可从模板外开始拖入，实际效果裁剪在模板 ROI 内。掩膜区域保存在 `MaskStroke.Shape/Width/Height`，旧 Job 只有 `Radius` 时按圆形兼容。
- 掩膜坐标使用原图像像素坐标，与画布缩放和平移无关。
- 橙色点是当前会写入 Shape Model 的点，掩膜操作后会立即刷新。
- 运行时不重新应用模板掩膜；被排除区域在模型中没有模型点，因此不会直接参与评分。

搜索 ROI 默认开启。新建 Job 时，黄色搜索框会按模板 ROI 向四周外扩固定 `100px`，该值不再作为页面参数；搜索框仍可在画布中手动调整。关闭“启用搜索区域”后才会改为全图搜索。

模板中心仍固定为模板 ROI 的几何中心，现有定位坐标计算方式不变。示教画布会在模板 ROI 内绘制贯穿整个 ROI 的水平、垂直十字线，用于直观看到该中心。

## 6. 参数兼容

原流程中的关键参数均保留在 `MarkMatchParameters`：

- `TemplateMeanSize` / `SearchMeanSize`
- `EdgeSigma` / `EdgeLowThreshold` / `EdgeHighThreshold`
- `FeatureMinDistancePx` / `MaxFeaturePoints`
- `AngleStartDegrees` / `AngleExtentDegrees`
- `ScaleMin` / `ScaleMax`
- `MinScore`
- `NumLevels`
- `MinContrast`
- `UsePolarity`
- `MaxOverlap` / `Greediness`（页面隐藏，保留默认值用于兼容）

页面不再选择“模板匹配”和“找圆”。上位机通过 `MarkLocateJob.EnableTemplateMatching` 和 `MarkLocateJob.EnableCircleDetection` 控制流程：前者默认 `true`，后者默认 `false`。两者都启用时先做形状匹配再进行圆心精修；仅启用找圆时使用搜索 ROI（未启用时使用模板 ROI）作为初始区域，匹配模型不是必需的。结果仍写入 `CircleFound`、`CirclePoint` 和 `CircleRadius`。

新建 Job 的默认匹配角度为 `-180°` 到 `180°`，对应 `AngleStartDegrees=-180`、`AngleExtentDegrees=360`。

掩膜笔刷半径 `BrushRadius` 的默认值为 `18px`。

页面仅保留常用的滤波、点间距、画笔尺寸、建模和搜索参数；Sigma、边缘高低阈值、最大特征点数、最大重叠、贪婪度等仍保存在 `MarkMatchParameters`，由内部默认值或上位机配置驱动，不再显示在设置页。修改建模参数、模板 ROI 或掩膜后会清除旧模型并要求重新创建。

## 7. 部署注意事项

- 上位机进程必须为 x64。
- HALCON Runtime 版本必须与交付的 `halcondotnet.dll` 一致。
- `MarkLocateJob.TeachData.ModelBytes` 已包含训练后的 Shape Model，不要只保存模板 Bitmap。
- `MarkLocateJob` 的持久化由上位机现有产品配置机制负责。
- 多相机或多产品应分别保存各自的 `MarkLocateJob`，不要在运行线程中修改同一个 Job。
