# 上位机接入说明

## 1. 交付文件

Release 构建后，上位机至少需要以下文件：

- `Seprays.MarkVision.dll`
- `halcondotnet.dll`
- 当前设备已安装且与 `halcondotnet.dll` 对应的 HALCON 19.11 x64 Runtime

项目目标框架为 `.NET Framework 4.7.2`，平台为 `x64`。

## 2. 新旧流程映射

| 原 Seprays.Vision 流程 | 新流程 | 说明 |
| --- | --- | --- |
| `DealShapeModel` | `OpenSetupDialog` | 模板 ROI 确定后自动提取离散特征点，可擦除不稳定点后建模。 |
| 保存 `Bitmap Mark` | 保存 `MarkLocateJob` | Job 包含 ROI、匹配参数、擦除笔划、特征点和模型字节。 |
| `FindShape` | `RunInspection` | 仍使用 `FindScaledShapeModel`，返回中心、分数、角度、缩放和轮廓。 |
| `FindResult.ModelPoint` | `MarkLocateResult.ModelPoint` | 坐标均为原图像像素坐标。 |
| `FindResult.Score` | `MarkLocateResult.Score` | HALCON 形状匹配分数。 |

原算法的主要顺序保持不变：模板预处理、缩放形状模型、运行图预处理、搜索范围、缩放形状匹配。创建模型前新增外轮廓流程：模板 ROI 内执行亚像素边缘提取，将擦除笔划应用到离散特征点，再通过 `CreateScaledShapeModelXld` 创建模型。

## 3. Mark 点设置页面

最终用户流程集中在 `MarkSetupControl` 页面内：通过唯一的“加载图片”入口载入图片，点击“添加模板 ROI”并手绘，调整参数和掩膜后创建模型。再次加载图片即可直接测试，保留 `TeachData.ModelBytes`、模板 ROI、掩膜及参数；也可以直接测试创建模板时的当前图片。

上位机通过 `OpenSetupDialog` 打开设置页面，点击底部“确认”后取得完成的 Job：

```csharp
using Seprays.MarkVision;

private readonly MarkLocatorSdk _markSdk = new MarkLocatorSdk();
private MarkLocateJob _markJob;

private void OpenMarkSetup(Bitmap teachImage)
{
    MarkLocateJob edited = _markSdk.OpenSetupDialog(teachImage, _markJob);
    if (edited != null) _markJob = edited;
}
```

在设置页面通过“加载图片”换图。控件内部缓存模板来源图，修改特征参数或掩膜时显示该来源图并据此重建；测试始终使用最近加载的当前图片。“添加模板 ROI”把当前图片设为新的模板来源。

仓库中的 Demo 以普通可调整大小的窗口启动，复用带“确认/取消”按钮的 `MarkSetupForm`。确认后可通过窗体的 `Job` 属性取得配置。

## 4. 对话框方式

```csharp
using Seprays.MarkVision;

private readonly MarkLocatorSdk _markSdk = new MarkLocatorSdk();
private MarkLocateJob _markJob;

private void ConfigureMark(Bitmap cameraImage)
{
    MarkLocateJob edited = _markSdk.OpenSetupDialog(cameraImage, _markJob);
    if (edited != null)
    {
        _markJob = edited;
        // MarkLocateJob 由上位机写入自己的产品配置。
    }
}

private MarkLocateResult FindMark(Bitmap cameraImage)
{
    MarkLocateResult result = _markSdk.RunInspection(cameraImage, _markJob, returnResultImage: true);

    if (!result.Success)
    {
        // 上位机记录 result.Message，并按定位失败处理。
    }

    // result.ResultImage 包含匹配轮廓、中心点和找圆结果。
    // 使用完后由上位机调用 result.ResultImage?.Dispose()。
    return result;
}
```

用户取消设置对话框时返回 `null`，原 Job 不会被修改。

当前参与编译的 SDK 为 `SafeSources/MarkLocatorSdkImpl.cs`，公开以下接口：

- `OpenSetupDialog(Bitmap image, MarkLocateJob currentJob)`
- `RunInspection(Bitmap image, MarkLocateJob job, bool returnResultImage = false)`：同步返回定位结果；传 `true` 时生成效果图。

`OpenSetupDialog` 从 STA 线程调用时直接打开窗口，从非 STA 线程调用时自动创建 STA 线程并等待用户完成。直接操作 WinForms 控件应在 UI（STA）线程进行。设置控件在建模或测试期间禁用画布，拒绝加载新配置；`ValidateConfiguration` 在此期间返回 `false`，待操作结束后再确认配置。

## 5. 图像所有权

- SDK 不会释放、修改或长期持有上位机传入的 `Bitmap`；传入图像仍由上位机负责释放。
- `returnResultImage: false` 不分配效果图，`ResultImage` 为 `null`；传 `true` 时返回与输入尺寸相同的独立 `Bitmap`。检测失败且输入图片非空时也返回图片；输入为空时返回失败结果且效果图为 `null`。
- 定位结果包含原图坐标系的 `MatchedContours`、`ModelPoint`、分数、角度、缩放和找圆结果。效果图中的蓝色轮廓、绿色中心十字和橙色圆使用相同坐标。上位机负责释放 `ResultImage`；释放后不影响原图。

## 6. 特征点和掩膜语义

- 新建配置时模板 ROI 和搜索 ROI 默认为空且不显示；点击顶部“添加模板 ROI”或“添加搜索区域 ROI”后，在图像上拖拽创建，创建后拖动内部移动、拖动手柄缩放。滚轮缩放视图，中键平移。模板 ROI 创建或拖动完成后，页面自动提取并显示橙色离散特征点。
- 页面支持矩形、圆形、菱形三种模板 ROI，默认矩形。矩形使用八个控制点；圆形采用圆心向外创建和四个半径控制点等比缩放；菱形使用四个顶点。形状保存在 `MarkLocateJob.TemplateRoiShape`。
- 掩膜仅支持设置区的“画笔掩膜”按钮。按住鼠标左键涂抹，半径由 `BrushRadius` 控制；一次连续涂抹作为一笔撤销，设置区同时提供撤销和清空按钮。操作保存在 `MaskStroke`，旧 Job 仍兼容读取。
- 掩膜坐标使用原图像像素坐标，与画布缩放和平移无关。
- 橙色点是用于重建 XLD 轮廓的采样点，掩膜操作后立即刷新；HALCON 会进一步根据金字塔和优化设置生成实际模型点。
- 运行时不重新应用模板掩膜；被排除区域在模型中没有模型点，因此不会直接参与评分。

搜索 ROI 由操作者显式创建。点击“添加搜索区域 ROI”会自动启用搜索限制，随后在画布上拖拽；黄色区域可继续移动和缩放，整个过程保留已创建模型。未绘制或关闭“启用搜索区域”时使用全图搜索。

模板中心仍固定为模板 ROI 的几何中心，现有定位坐标计算方式不变。示教画布会在模板 ROI 内绘制贯穿整个 ROI 的水平、垂直十字线，用于直观看到该中心。

圆形模板 ROI 在归一化后使用等宽等高的边界；宽高不等的输入按较长边扩为圆形边界，并限制在图像内。提取、过滤和画布使用一致的圆形范围。

## 7. 参数兼容

原流程中的关键参数均保留在 `MarkMatchParameters`：

- `TemplateMeanSize` / `SearchMeanSize`
- `EdgeSigma` / `AutoEdgeThreshold`（默认 `true`，使用 HALCON 梯度分析自动计算高低阈值；手动修改高低阈值时自动切为手动模式） / `EdgeLowThreshold` / `EdgeHighThreshold`
- `FeatureMinDistancePx`（默认 `2.0px`） / `MaxFeaturePoints`
- `AngleStartDegrees` / `AngleExtentDegrees`
- `ScaleMin`（默认 `0.95`） / `ScaleMax`（默认 `1.05`）
- `MinScore`（默认 `0.70`）
- `NumLevels`
- `MinContrast`
- `UsePolarity`（历史名称：true 表示忽略局部极性，false 表示只忽略全局极性；后者从均值滤波后的模板图补回 XLD 边缘极性）
- `Greediness`（默认 `0.50`，开放编辑）
- `MaxOverlap`（兼容保留；当前只返回一个匹配结果，因此界面不开放此无实际作用的选项）

页面不再选择“模板匹配”和“找圆”。上位机通过 `MarkLocateJob.EnableTemplateMatching` 和 `MarkLocateJob.EnableCircleDetection` 控制流程：前者默认 `true`，后者默认 `false`。两者都启用时先做形状匹配再使用 HALCON Metrology 进行圆心精修；仅启用找圆时使用搜索 ROI（未启用时使用模板 ROI）作为初始区域，匹配模型不是必需的。结果仍写入 `CircleFound`、`CirclePoint` 和 `CircleRadius`。

新建 Job 的默认匹配角度为 `-5°` 到 `5°`，对应 `AngleStartDegrees=-5`、`AngleExtentDegrees=10`；默认启用 `AutoEdgeThreshold=true`。

画笔掩膜的默认半径 `BrushRadius` 为 `6px`；画笔以沿途圆形笔触连续覆盖。

页面显示模板均值滤波、边缘 Sigma、自动阈值开关、边缘低阈值、边缘高阈值、点间距、最大特征点数、画笔尺寸、建模和搜索参数。修改建模参数、模板 ROI 或掩膜后会清除旧模型并要求重新创建；仅修改运行参数时保留模型。

高低阈值联动保证低阈值小于高阈值，显示值与传入算法的值一致。`MinContrast` 支持 1–255，不再被未参与 XLD 建模的旧 `Contrast=30` 属性截断。角度和缩放范围也是模型创建范围，调整后需要重建；搜索 ROI、运行均值滤波、最低分数和贪婪度不需要重建。

设置页面的“测试定位”与上位机调用 `RunInspection` 共用同一条 `RunInspectionCore` 执行链路（保留原始像素格式并输出一致分数、位姿与找圆结果），并在每次调用时自动将来源（`页面测试` / `上位机SDK`）、分数、坐标、角度、缩放、找圆结果、耗时及错误信息追加写入 `D:\MarkVision_RunLog_yyyyMMdd.log`。

示教完成后，页面应保存 `OpenSetupDialog` 返回的 `MarkLocateJob`。测试另一张图片时，直接调用 `RunInspection(testImage, job, false)`，原模板 ROI、参数、掩膜和 `TeachData.ModelBytes` 都会继续使用，不需要在示教页面内重新导入或建模。

## 8. 部署注意事项

- 上位机进程必须为 x64。
- HALCON Runtime 版本必须与交付的 `halcondotnet.dll` 一致。
- `MarkLocateJob.TeachData.ModelBytes` 已包含训练后的 Shape Model，不要只保存模板 Bitmap。
- `MarkLocateJob` 由上位机现有产品配置机制持久化；SDK 仅提供打开设置和运行检测两个入口。
- 多相机或多产品应分别保存各自的 `MarkLocateJob`，不要在运行线程中修改同一个 Job。
- 若运行机存在 `D:\` 根目录，每次定位与建模都会自动记录日志到 `D:\MarkVision_RunLog_yyyyMMdd.log`；无 `D:\` 或磁盘不可写时不影响正常检测返回。
